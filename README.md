# The Little Prince: Animated Book Trailer

A dreamy, fully animated book trailer for *The Little Prince* by Antoine de Saint-Exup&eacute;ry.
It is plain HTML, CSS and JavaScript with no build step.

## What it does
- Twinkling starfield with shooting stars on a canvas
- Slow cinematic camera moves over your own illustration
- Fading captions you write yourself
- A glowing dawn and a final title card

## Use your own artwork
1. Save your illustration as `assets/artwork.png` (a 4:3 image works best).
2. Open `index.html` in a browser. Press space to replay.

## Edit the story
Change the `SCENES` list at the top of `script.js`: caption text and how long each scene lasts.
Write your own lines rather than quoting the book.

## Publish on GitHub Pages
1. Create a repository and push these files.
2. In Settings, open Pages and choose the main branch.
3. Your trailer will be live at `https://<your-username>.github.io/<repo-name>/`.

## Note
Only use artwork you made or have permission to use.
